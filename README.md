# avito_instant

Бот следит за поисковой выдачей Avito и сообщает о новых объявлениях.
Каждые ~10 секунд он открывает настроенные поиски в браузере, находит
объявления, которых ещё не видел, проверяет их по фильтрам (цена, слова
в заголовке) и:

- печатает в консоль цену (выделена цветом) и кликабельную ссылку;
- дописывает строку `время, цена, заголовок, ссылка` в `found.txt`.

Avito защищён антиботом (Qrator), поэтому обычные HTTP-запросы блокируются.
Бот работает через настоящий браузер Chromium (Playwright) с сохраняемым
профилем: если Avito покажет капчу, её нужно один раз решить в окне браузера,
дальше кукисы сохраняются в `.browser_profile/`. Вход в аккаунт Avito не нужен.

## Запуск на Windows

### 1. Установить Python

Скачайте Python 3.11 или новее с <https://www.python.org/downloads/windows/>.
В установщике **отметьте галочку «Add python.exe to PATH»**.

Проверка (в PowerShell или cmd):

```powershell
python --version
```

### 2. Получить проект

Склонируйте репозиторий (`git clone ...`) или скопируйте папку проекта,
затем перейдите в неё:

```powershell
cd C:\путь\к\avito_instant
```

### 3. Создать виртуальное окружение и установить зависимости

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m playwright install chromium
```

Последняя команда скачивает браузер Chromium (~150 МБ), это делается один раз.

### 4. Настроить поиски

Откройте `config.yaml` в любом редакторе и поправьте под себя.

**Включить / выключить поиск** — `enabled: true` / `enabled: false` у нужного
пункта в `searches`. При запуске бот пишет, какие поиски активны.

**Оперативная память** настраивается блоком `ram`, регулярки писать не нужно:

```yaml
  - name: ram
    enabled: true
    price_min: 1000
    price_max: 4000
    ram:
      type: ddr4        # ddr3 / ddr4 / ddr5; null — любой
      total_gb: 32      # общий объём; null — любой
      sticks: 2         # сколько планок: 1, 2, 4; null — любое
```

- `total_gb: 32, sticks: 2` — комплекты 2×16 («2x16», «16gb x2», «2 шт по 16»…);
- `total_gb: 16, sticks: 1` — одна планка 16 ГБ, комплекты отсеиваются;
- `total_gb: 16, sticks: null` — любой вариант: 1×16, 2×8, 4×4.

Фильтр смотрит только на заголовок: объявление без «DDR4» в заголовке при
`type: ddr4` не пройдёт, а «32gb» без указания планок не пройдёт при `sticks: 2`.

**Общие параметры поиска:**

- `price_min` / `price_max` — диапазон цен;
- `require` — регулярные выражения, все должны найтись в заголовке;
- `include` — регулярные выражения, хотя бы одно должно найтись в заголовке;
- `exclude` — регулярные выражения, при совпадении объявление пропускается.

`interval_seconds` в начале файла — пауза между циклами опроса.
`show_rejected: true` — новые объявления, не прошедшие фильтры, выводятся в консоль
серым с причиной («не DDR4», «цена > 24000», «исключение «ECC»»…); `false` — скрыть их.

Чтобы добавить свой поиск, проще всего настроить фильтры прямо на сайте Avito,
скопировать адрес страницы и добавить в `searches`:

```yaml
  - name: my_search
    enabled: true
    url: "https://www.avito.ru/moskva/..."
    price_max: 5000
```

### 5. Запустить

```powershell
.venv\Scripts\python bot.py
```

- Откроется окно Chromium — его можно свернуть, но **не закрывайте**:
  закрытие окна останавливает бота.
- Если в консоли появилось «Avito просит пройти капчу», решите капчу в окне
  браузера — бот продолжит сам.
- Остановить бота: `Ctrl+C` в консоли.
- Один цикл и выход (для проверки): `.venv\Scripts\python bot.py --once`.

При самом первом запуске бот только запоминает текущие объявления (в `seen.json`),
чтобы не записать в `found.txt` всю выдачу разом. Новые объявления появятся
со следующих циклов.

### Консоль

Цвет цены и кликабельные ссылки лучше всего работают в **Windows Terminal**
(стоит по умолчанию в Windows 11, для Windows 10 — из Microsoft Store).
Ссылка открывается по `Ctrl+клик`. В старой консоли cmd цвет будет, а заголовок
может не быть кликабельным — тогда используйте полный URL на строке ниже.

## Файлы

| Файл | Назначение |
|---|---|
| `bot.py` | сам бот |
| `config.yaml` | настройки и список поисков |
| `found.txt` | найденные объявления (создаётся автоматически) |
| `seen.json` | id уже просмотренных объявлений (создаётся автоматически) |
| `.browser_profile/` | профиль браузера с кукисами Avito (создаётся автоматически) |

Чтобы начать «с чистого листа», удалите `seen.json`. Если Avito перестал пускать
даже после капчи, удалите папку `.browser_profile/`.

## Ограничения

- Работает только с видимым окном браузера (`headless: false`): в фоновом
  режиме Avito блокирует запросы.
- Частый опрос может чаще вызывать капчу — в этом случае увеличьте
  `interval_seconds`.
